Punctul de plecare

Cum transformăm un site într-o experiență?

Un vizitator care intră într-o școală are nevoie de orientare, informații și un motiv să-și amintească locul. Un site clasic oferă conținut, dar nu oferă aceeași experiență ca o recepție interactivă.

„Nu am construit doar un site despre liceu. Am construit un prim contact digital cu liceul.”
HandWave03 / 08
Soluția

O recepție digitală pentru o școală modernă

🖐️

Interacțiune naturală

Camera poate detecta mâna, iar degetul arătător devine cursor. Mouse-ul rămâne un fallback sigur.

🧺

Învățare prin joc

Un joc scurt transformă timpul de așteptare într-o experiență memorabilă și interactivă.

🌐

Tur pe orice dispozitiv

Turul 360° poate fi explorat pe ecran, laptop sau telefon, fără instalarea unei aplicații.

Tehnologia din spatele gesturilor

Interacțiune direct în browser

MediaPipe identifică punctele mâinii. Arătătorul este urmărit ca un cursor, iar gesturile pot activa elementele interfeței.

Aplicația revine automat la mouse dacă nu există cameră, permisiuni sau conexiune suficientă.

const Kiosk = { mana(points) { setMode('mana'); cursor.move(points[8]); detectClick(points); } };

Turul virtual

Școala devine explorabilă la 360°

Patru spații

HandWave07 / 08
Ce am folosit și ce am învățat

Un proiect web complet, nu doar o pagină

Tehnologii

HTML, CSS, JavaScript pentru interfață și logică · MediaPipe pentru mână · A-Frame pentru scena 360° · GitHub Pages pentru publicare.

Decizii importante

Fallback la mouse, design responsive, suport pentru tastatură, reducerea animațiilor și folosirea locală a camerei fără salvarea cadrelor video.
